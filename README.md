# Feira de Ciências — Coleção Biológica

Site estático HTML, sem necessidade de instalar dependências.

## Publicação na Vercel por meio do GitHub

1. Crie um repositório GitHub, por exemplo `feira-colecao-biologica`.
2. Adicione o arquivo `index.html` na raiz do repositório (não envie apenas este ZIP como um arquivo isolado).
3. Na Vercel, use **Add New > Project > Import Git Repository** e selecione esse repositório.
4. Para a página estática, escolha **Other** ou nenhum framework. Não precisa de comando de build.
5. Faça Deploy e copie o endereço de produção, por exemplo `https://nome-escolhido.vercel.app`.
6. Teste os endereços de cada exemplar e, depois, gere os QR Codes a partir da URL real publicada.

## Links para os cinco exemplares

Substitua `https://SEU-DOMINIO` pela URL pública definitiva. Conserve os identificadores do parâmetro `exemplar`:

- `https://SEU-DOMINIO/?exemplar=mallophora`
- `https://SEU-DOMINIO/?exemplar=lethocerus`
- `https://SEU-DOMINIO/?exemplar=panstrongylus`
- `https://SEU-DOMINIO/?exemplar=cissites`
- `https://SEU-DOMINIO/?exemplar=hamadryas`

**Importante:** os cinco links apontam para o mesmo `index.html`, exibindo espécies diferentes conforme o parâmetro. Não gere QR Codes de produção antes de conhecer e testar a URL pública final.

## Revisão científica

Fotografias e informações do acervo devem ser conferidas antes da divulgação. A identificação do arrebenta-boi permanece indicada pelo responsável da coleção, ainda a verificar pela morfologia diagnóstica. Revise também eventuais dados de etiqueta parcialmente legíveis.
